## Assignment 1: Regression
**Weight**: 25 points  
**Objective**: Implement linear and polynomial regression models to analyze relationships between variables, focusing on both implementation and visualization.

### Part 1:
- **Dataset**: World Happiness Dataset (2018)  
- **Skills**: Gradient Descent implementation, Linear Regression, Data Visualization  
- **Tools**: Python, NumPy, Matplotlib  
- **Key Features**:  
  - Analysis of relationship between happiness scores and GDP using multiple learning rates and iteration counts

### Part 2:
- **Dataset**: Abalone Dataset  
- **Skills**: Feature Analysis, Model Selection, Performance Evaluation  
- **Tools**: Python, NumPy, Matplotlib  
- **Key Features**:  
  - Age prediction using physical measurements, model comparison and evaluation

---

## Assignment 2: Supervised Machine Learning
**Weight**: 25 points  
**Objective**: Implement Support Vector Machine (SVM) classifier for solar flare prediction using multiple feature sets.

- **Dataset**: NASA Solar Dynamics Observatory (SDO) satellite data (2010-2015 and 2020-2024)  
- **Skills**: Feature Engineering, SVM Implementation, Cross-Validation, Performance Metrics  
- **Tools**: Python, NumPy, SciPy  
- **Key Features**:  
  - Solar flare prediction  
  - Feature set analysis  
  - K-fold cross-validation  
  - True Skill Score evaluation

## Assignment 3: SVM
**Weight**: 25 points  
**Objective**: Implement advanced SVM techniques including regularization, mini-batch processing, and active learning.

- **Dataset**: Breast Cancer Dataset  
- **Skills**: SVM Implementation, Early Stopping, Mini-batch Processing, Active Learning  
- **Tools**: Python, NumPy, SciPy  
- **Key Features**:  
  - Implementation of early stopping regularization  
  - Mini-batch stochastic gradient descent  
  - Active learning for optimal sample selection

## Assignment 4: Algorithmic Bias & ML Architectures
**Weight**: 25 points  
**Objective**: Implement CNN for image classification and analyze algorithmic bias in criminal justice predictions.

### Part 1:
- **Dataset**: Fashion-MNIST  
- **Skills**: CNN Architecture Design, Model Training, Performance Benchmarking  
- **Tools**: PyTorch, NumPy  
- **Key Features**:  
  - Implementation of lightweight CNN for fashion product classification  

### Part 2:
- **Dataset**: COMPAS Recidivism Dataset (ProPublica)  
- **Skills**: Bias Detection, Logistic Regression, Fair ML  
- **Tools**: PyTorch, NumPy  
- **Key Features**:  
  - Implementation of bias detection and mitigation strategies in recidivism prediction
